# BelfastIA — Gestión Colaborativa de Obra

## Instalación en el teléfono (10 minutos)

### PASO 1 — Subir a Vercel

1. Entrá a **github.com** y creá una cuenta gratuita
2. Creá un repositorio nuevo → llamalo `belfastia`
3. Subí todos los archivos de esta carpeta
4. Entrá a **vercel.com** → creá cuenta con GitHub
5. "Add New Project" → seleccioná el repo `belfastia`
6. Click en **Deploy** → en 2 minutos tenés tu URL

### PASO 2 — Instalar como app

**iPhone (Safari):**
1. Abrí tu URL de Vercel en Safari
2. Botón compartir ⬆️ → "Agregar a pantalla de inicio"
3. ¡Listo! Aparece el ícono de BelfastIA

**Android (Chrome):**
1. Abrí tu URL en Chrome
2. Menú ⋮ → "Agregar a pantalla de inicio"
3. ¡Listo!

### PASO 3 — Configurar API Key

1. Abrí BelfastIA
2. Pegá tu API Key de Anthropic (console.anthropic.com)
3. Tocá OK → ingresá como Estudio o Constructora
